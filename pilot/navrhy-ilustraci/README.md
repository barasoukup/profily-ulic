# Nepoužívané varianty pražských ilustrací

Aplikace je nekreslí a na web se nenasazují (nasazuje se jen `pilot/public`). Jsou tu pro případ,
že by se hodily: klasická lavička, klasický přístřešek (s tramvajovým označníkem i bez) a totem
z návrhů Olgoj Chorchoj a starší verze tramvaje. Licence jako zbytek repozitáře (MIT).
